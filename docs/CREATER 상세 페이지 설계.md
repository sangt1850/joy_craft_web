3. ① 코드 에디터 영역
   Monaco Editor (VS Code 엔진) 사용. 시작 템플릿 선택 시 아래 코드가 미리 채워져 있다.
   시작 템플릿 코드 예시 (질문 + 도망 버튼)
   import { PageProps } from '@joycraft/sdk'

import { motion } from 'framer-motion'

import { useState, useRef } from 'react'

export default function QuestionPage({ data }: PageProps) {

const {

    questionText,

    yesText,

    noText,

    yesColor,

    noSpeed,

    fontSize,

    fontFamily,

    backgroundImage,

    backgroundColor,

} = data

const [noPosition, setNoPosition] = useState({ x: 0, y: 0 })

const containerRef = useRef<HTMLDivElement>(null)

const handleNoHover = () => {

    // 아니오 버튼이 랜덤 위치로 도망

    const x = Math.random() * 200 - 100

    const y = Math.random() * 200 - 100

    setNoPosition({ x, y })

}

const handleYesClick = () => {

    // 예 클릭 시 다음 페이지로 이동

    window.joycraft.nextPage()

}

return (

    <div

      ref={containerRef}

      style={{

        fontFamily,

        fontSize,

        backgroundColor,

        backgroundImage: backgroundImage

          ? `url(${backgroundImage})`

          : undefined,

        backgroundSize: 'cover',

        height: '100%',

        display: 'flex',

        flexDirection: 'column',

        alignItems: 'center',

        justifyContent: 'center',

        gap: '2rem',

      }}

    >

      <h1>{questionText}</h1>

      <div style={{ display: 'flex', gap: '1rem' }}>

        <button

          onClick={handleYesClick}

          style={{ background: yesColor, padding: '12px 32px' }}

        >

          {yesText}

        </button>

        <motion.button

          animate={noPosition}

          transition={{ duration: 1 / noSpeed }}

          onHoverStart={handleNoHover}

          onTouchStart={handleNoHover}

          style={{ padding: '12px 32px' }}

        >

          {noText}

        </motion.button>

      </div>

    </div>

)

}

12. 데이터 흐름 전체 (CREATOR → CUSTOMER)
    [CREATOR - Web IDE]

    │

    ├── code: "export default function..."

    ├── schema: { fields: [...] }

    └── meta: { name, category, ... }

             ↓ 심사 승인

             ↓

[DB - component_types 테이블]

     │

     ├── component_ref: 빌드된 JS 번들 경로

     ├── schema: jsonb

     └── platformMode: "responsive"

             ↓

[CUSTOMER - 페이지 둘러보기]

     │

     └── 페이지 선택 → 템플릿에 추가

             ↓

[CUSTOMER - 에디터]

     │

     ├── 좌측: 페이지 목록

     ├── 중앙: 미리보기 (컴포넌트 렌더링)

     └── 우측: 편집 패널 (schema 기반 자동 생성)

             │

             ├── questionText: "승현아 나 좋아해?"

             ├── yesColor: "#4a90d9"

             └── noSpeed: 2.0

             ↓

[DB - site_slides 테이블]

     │

     └── overrides: { "questionText": "승현아 나 좋아해?", ... }

             ↓

[렌더러 - 사이트 재생]

     │

     ├── default_values + overrides → merge

     ├── merge 결과를 data props로 주입

     └── React 컴포넌트 렌더링

             ↓

부록: 추후 비주얼 빌더 도입 시 구조
Web IDE의 코드 에디터 자리에 드래그 & 드롭 캔버스가 들어간다. 스키마 빌더와 메타 정보 영역은 그대로 유지.

현재 (Web IDE):

[코드 에디터] [미리보기] [스키마 빌더 / 메타]

추후 (비주얼 빌더 추가):

모드 전환: [코드] [비주얼]

비주얼 모드:

[캔버스 (드래그&드롭)] [미리보기] [스키마 빌더 / 메타]

스키마 빌더와 미리보기 구조가 동일하므로, 비주얼 빌더는 "코드 에디터 영역만 교체"하면 된다. 나머지 인프라(스키마 저장, 미리보기 렌더링, 심사 프로세스)는 재사용.
